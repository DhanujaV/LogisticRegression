# 📊 Sentiment Analysis Using Logistic Regression

A Machine Learning project that analyzes and classifies text sentiments as **Positive**, **Negative**, or **Neutral** using **Logistic Regression** and Natural Language Processing (NLP) techniques.

## 🚀 Features

- Text preprocessing and cleaning
- Tokenization and stopword removal
- TF-IDF feature extraction
- Logistic Regression model training
- Sentiment prediction on new text
- Performance evaluation using accuracy metrics

## 🛠️ Technologies Used

- Python
- Scikit-learn
- Pandas
- NumPy
- NLTK
- Matplotlib
